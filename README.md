# NixOS

As of now my NixOS systems are managed by home-manager. I started with testing NixOS on a thinkpad t440s. I liked it enough that I used my Forgejo instance and home-manager to clone what I had done on the t440s to my main laptop, a thinkpad t480.
Once I was done getting the t480 setup and learned my way around the system a little bit I decided to switch my gaming desktop over to NixOS as well. I loved Arch linux for almost the last two years. I think that I have found my new favorite
distro of choice. Here it is.
